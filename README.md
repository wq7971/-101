# 🛡️ 坦克大战 (Tank Battle)

一个使用纯 HTML + Canvas + JavaScript 编写的经典坦克大战游戏，无需任何依赖，打开即玩。

## 🕹️ 在线试玩

👉 **https://wq7971.github.io/-101/**

## ✨ 功能特性

- 🎮 经典坦克大战玩法：移动、射击、摧毁敌方坦克
- 🧱 可破坏的砖墙 & 不可破坏的钢墙
- 🏰 需要保卫的基地（基地被毁则游戏失败）
- 🤖 敌方坦克 AI（随机移动 + 概率瞄准玩家）
- 📈 5 个关卡，难度递增
- 🔊 使用 Web Audio API 合成的音效（无需音频文件）
- 🎯 粒子爆炸特效、无敌闪烁、生命/得分系统
- ⌨️ 支持键盘操作，暂停功能

## 🎮 操作方式

| 按键 | 功能 |
|------|------|
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 移动坦克 |
| `空格` 或 `J` | 发射炮弹 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

## 🚀 快速开始

直接用浏览器打开 `index.html` 即可游玩，无需安装任何依赖。

也可以使用本地服务器：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🎯 游戏规则

1. 摧毁所有敌方坦克即可过关
2. 保护你的基地（底部中央的鹰形标志），基地被毁则游戏失败
3. 每摧毁一辆敌方坦克得 100 分
4. 通关每关可获得额外奖励分
5. 共 5 个关卡，全部通关即胜利
